# 经济基础决定上层建筑

这是一款马克思政治经济学演示。历史是一张顺着生产力正方向生长的图。玩家在图的末端遇见事件，再选择事件的结果。经济基础决定开局的上层建筑和社会形态，事件结果再推动三轴、上层建筑和生产力。

游戏分成三个模块：

- 生产力图。核心节点拼到当前末端时，生产力坐标保持不变。遇见事件本身不提高生产力，只有选定的结果才改变生产力。
- 三轴。按教材分为生产资料所有制、生产地位关系、分配关系。
- 上层建筑。按教材分为政治上层建筑和观念上层建筑。讨论记录见 [上层建筑设计](https://chat.deepseek.com/share/pshebrlgo00r0ptgd4)。本文把这一层做成可计算的两层树。

## 开局

玩家按影响力从重到轻，分三级选择初始经济基础：

1. 生产资料所有制
2. 生产地位关系
3. 分配方式

每一级只展示与上一选择相容的选项。这三项就是三轴，并直接生成初始上层建筑和社会形态。然后在生产力图上放一个坐标为 0 的起点。起点就是当前末端。

## 一轮事件

1. 当前节点是末端时，按当前生产力、历史路径、三轴和上层建筑条件，从事件库抽一个事件。
2. 把事件的核心节点与当前末端拼在同一生产力坐标上。这一步不改变生产力。
3. 核心之外的节点都是新的末端，代表不同选择。节点相对核心的位置，是该选择对生产力的设计增量，另外可以改三轴和上层建筑。
4. 玩家选定一个末端。正增量要乘修正系数。关键事件的正确结果使用完整增量。
5. 走到新末端后，若它仍然没有后继，就再抽取、再拼接。
6. 生产力达到 180 时，游戏结束。

## 修正和时代

修正用来表现生产力饱和，也就是软性锁。每个事件有一个最适生产力。当前生产力离它越远，修正越接近 0。

狩猎采集走到顶峰时，石器、采集、铜矿利用这类普通事件的正增量会乘到接近 0。只有「定居发展农业」这种关键事件的正确结果还能把生产力提高一截，并提示进入农业时代，随后才能抽到依赖这段历史的新事件。

时代不是硬划分，也没有按时代切开的结构库。它是一段历史走完后被揭示出来的生产力水平。只有关键事件达成正确结果时，才提示进入新时代。蒸汽机不会在石器时代被抽到，因为它要求的生产力区间还没到。青铜冶炼则要求已经走过铜矿利用。

## 上层建筑如何返回来

事件结果可以点亮上层建筑、推动三轴。上层建筑不直接改生产力数值。它写入历史条件：以后的抽取倍率、三轴偏向、修正偏置，以及被门闩挡住的关键事件。下一轮抽取才读取这些条件。

因此玩家能感到的回路是：初始经济基础决定上层建筑，选择改变三轴和上层建筑，上层建筑改写后续事件的概率和修正，生产力和经济基础再跟着变。社会形态名称只负责显示。长期差别看条件标签。

三轴之间，所有制决定生产地位和分配里哪些关系站得住。两者和所有制不匹配时形成张力。张力压低普通事件的有效修正，并让更贴近所有制的关系在以后的事件里更容易被选中。

## 开发思路

事件模板、三轴节点、上层建筑节点都做成数据。抽取、拼接、修正、合法性和条件编译做成纯函数。

模块之间只传四份快照：生产力坐标和历史路径，三轴签名，条件快照，效果列表。回合循环只负责把「抽事件、选择、结算、编译条件」按顺序串起来。

生产力模块不读取上层建筑节点。上层建筑模块不读取事件库的内部结构。历史条件只汇总和夹取。效果白名单拒绝上层建筑来源直接改写生产力。

建议的实现顺序：

1. 事件模板、原位拼接和修正。
2. 抽取权重：生产力区间、历史前置、顶峰时的关键事件加成。
3. 开局三级选择，以及由它生成的上层建筑和社会形态。
4. 三轴图、兼容度和事件结果里的轴进度。
5. 上层建筑树、滞后和历史条件。
6. 把上面的函数接成事件循环，生产力达到 180 时停止。
