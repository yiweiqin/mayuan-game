# 算法设计

本文给每个小模块一节算法。编号与 [module-graph.md](module-graph.md) 一致。玩法说明见 [README](../README.md)，流程见 [gameplay-flow.md](gameplay-flow.md)。

跨模块只传递下面的四份快照。随机数取自区间 \([0, 1)\)。加权抽取时，把 `roll × 权重总和` 落进累计权重区间。

`clamp(x, lo, hi) = min(hi, max(lo, x))`。

## 共用常数

| 名称 | 值 |
| --- | --- |
| 起点生产力 | 0 |
| 结束生产力 | 180。达到或超过即结束 |
| 修正 | \(\mathrm{e}^{-((P - P_{opt}) / 带宽)^2}\)，再夹到 [0, 1] |
| 顶峰线 | 当前能抽到的普通事件里，最高修正低于 0.2 |
| 顶峰加成 | 关键事件权重 × 3 |
| 残差权重 | 迁移时置 0.3，每轮事件减 0.05，到 0 清除 |
| 进度提交线 | 100 |
| 抽取倍率 | [0.5, 2]，缺省 1 |
| 轴偏向 | [0.5, 1.5]，缺省 1 |
| 修正偏置 | [-0.1, 0.1]，缺省 0 |
| 矛盾 | [0, 1]。滞后每点贡献 0.25 |
| 寻常点亮的矛盾上限 | 0.85 |
| 革命门槛 | 矛盾 ≥ 0.7，且所有制任一边的进度 > 0 |
| 危机 | 张力 ≥ 0.7，或矛盾 ≥ 0.7 |

交换方式只有四种标签：互惠交换、贡纳再分配、市场交换、计划调拨。它不占三轴，也不积累进度。

## 快照

生产力因子：当前生产力坐标、历史标记集合、已完成事件数、当前节点是否为末端。

三轴签名：三个主导节点、三个残差及其权重、交换标签、张力、每条边的进度。

条件快照：按标签索引的抽取倍率、按边编号索引的轴偏向、修正偏置、门闩集合。

效果：来源（生产力、经济基础、上层建筑）、目标、载荷、日志说明。

# M1 生产力

生产力模块拥有地图、事件库、生产力坐标和时代提示。它读取条件快照和历史标记，不读取上层建筑节点。

一个事件模板有一个核心节点，以及若干选择末端。核心节点上的最适生产力 \(P_{opt}\) 是计算修正和抽取适配时的参考值。它不是拼接后的坐标。拼接后的坐标永远等于当时的当前末端。

## A1 时代提示

输入：玩家刚选定的末端。

输出：一条时代提示，或空。

该末端标了「关键正确」并且写了时代名时，把时代名记入已揭示时代，并写入它声明的历史标记。没有关键正确结果时，不提示新时代，也不因为生产力跨过某个数就改时代。

已揭示时代只用于显示。事件能不能被抽到，由 A8 的生产力区间和历史标记决定。

## A2 事件抽取

输入：当前节点、A3 的权重、A8 滤出的候选。

输出：一个事件模板。当前节点必须是末端，也就是没有尚未选择的后继。

候选不为空时，按权重抽一个事件，交给 A4。候选为空时，本轮不拼接，游戏停在当前末端；事件库应当保证走到结束生产力之前总有候选。

## A3 抽取权重

输入：候选事件、当前生产力、条件快照、三轴与交换标签、普通事件修正的最大值。

输出：每个候选的权重。

```
适配 = A6 的基础修正(P, 事件.P_opt, 事件.带宽)
顶峰加成 = 1
若事件是关键，且普通事件最高修正 < 0.2，顶峰加成 = 3

交换契合 = 1
若事件声明了交换标签，且与当前交换方式相同，交换契合 = 1.4
若事件声明了交换标签，且与当前交换方式不同，交换契合 = 0.7

轴契合 = 1
若事件声明了分配偏好，且当前分配主导不在其中，轴契合 = 0.6

倍率 = 条件快照中该事件编号的倍率
若没有编号项，则用主标签的倍率
若仍没有，倍率 = 1

权重 = 基础权重 × 适配 × 顶峰加成 × 交换契合 × 轴契合 × 倍率
```

权重为 0 的事件不进入累计区间。

## A4 核心拼接

输入：当前末端 x、事件 S。

输出：更新后的地图。生产力坐标不变。

1. S 的核心与 x 重合，不新建核心，x 的生产力坐标保持原值。
2. 为每个选择末端新建节点，并连到 x。
3. x 离开末端集合。新节点成为可选末端，玩家还没选定当前节点。
4. 拼接本身不产生生产力效果，也不写入历史标记。

## A5 末端选择

输入：本事件的选择末端、玩家的选择。

输出：新的当前节点，以及该末端上的效果列表。

玩家必须选一个已经拼上的末端。选定后：

1. 当前节点改为该末端。
2. 该末端上的生产力载荷交给 A6、A7，来源记为生产力。
3. 三轴载荷交给 A18，来源记为经济基础。
4. 上层建筑载荷交给 A23，来源记为上层建筑。
5. 历史标记和时代名交给 A1。
6. 其余未选末端留在图上，以后的抽取只从新的当前末端继续。

## A6 修正系数

输入：当前生产力 P、事件的 \(P_{opt}\) 和带宽、张力、条件快照里的修正偏置、该末端是否为关键正确结果。

输出：用于正增量的有效修正。

```
基础修正 = clamp(exp(-((P - P_opt) / 带宽) ^ 2), 0, 1)
有效修正 = clamp(基础修正 × (1 - 0.25 × 张力) + 修正偏置, 0, 1)
```

张力和偏置只在读取时生效，不写回事件的 \(P_{opt}\)。

关键正确结果不使用有效修正，设计增量原额进入 A7。普通结果里的正增量乘有效修正。负的设计增量不乘修正，坏选择在饱和期仍然生效。

## A7 生产力数值

输入：当前坐标 P、设计增量、A6 的结算增量。

输出：新的生产力坐标，以及是否结束。

```
P = max(0, P + 结算增量)
```

新坐标同时写到刚选定的末端上，作为下一次拼接的起点。P 达到 180 时，本轮剩余的命名和条件编译仍做完，然后游戏结束，不再抽取。

## A8 历史前置

输入：事件库、当前 P、历史标记、门闩集合。

输出：候选列表。

同时满足才进入候选：

1. `P_min ≤ P ≤ P_max`。区间外权重直接为 0。石器时代因此抽不到蒸汽机。
2. 事件要求的每一个历史标记都已经存在。青铜冶炼要求 `copper_use`。
3. 若事件带门闩，编号必须在门闩集合里。
4. 已经作为当前链走过的事件编号不再进入候选。未选分支上的事件不算走过。

# M2 经济基础

经济基础模块拥有三张轴图、交换标签、张力和开局分级。它接收生产力坐标和条件快照，不遍历事件库。

## A9 三轴状态

每一轴保存主导节点、残差节点和残差权重，以及边进度表。开局主导节点由 A17 写入，残差为空，进度为 0。

每一轮事件开始时，残差权重变为 `max(0, 权重 - 0.05)`。到 0 时清除残差节点。

迁移提交时：残差改为旧主导，权重设为 0.3，主导改为边的终点，该边进度清 0。

## A13 边开放

一条边同时满足以下条件才开放：

1. 该轴主导节点等于边的起点。
2. 当前生产力不低于边的最低生产力。
3. A15 的兼容度不低于 0.2。

危机时，第 3 条改为兼容度大于 0。兼容度为 0 的边仍然关闭。

## A14 推进结算

输入：事件末端写明的边和进度增量。

输出：该边的新进度；达到 100 时按 A9 提交迁移。

边必须在结算当时开放。未开放则这条轴载荷拒绝并记日志，末端的生产力载荷仍然生效。增量原额加入进度，不再掷第二次骰。进度超过 100 的部分不带到下一条边。

| O5 | 0 | 0 | 0 | 0.3 | 0.6 | 1 | 0.3 |
| O6 | 0.3 | 0 | 0 | 0.6 | 0.3 | 0.3 | 1 |

残差混合。所有制残差权重为 wO，生产地位残差权重为 wL。残差为空时，残差节点等于主导节点，权重为 0。

```
c(生产地位) = (1-wO)×(1-wL)×表(主导O, 主导L)
            + wO×(1-wL)×表(残差O, 主导L)
            + (1-wO)×wL×表(主导O, 残差L)
            + wO×wL×表(残差O, 残差L)
```

分配用同一式子和分配表，得到 `c(分配)`。

边上的兼容度：

- 生产地位边、分配边：`(1-wO)×表(主导O, 终点) + wO×表(残差O, 终点)`。
- 所有制边：终点与当前生产地位、分配的兼容度取平均。

因此在 O0、L0、D0 下，`E_O0_O1` 的兼容度是 `(0.3 + 0.3) / 2 = 0.3`，可以开放。`E_L0_L1` 的兼容度是 0，要等所有制先离开 O0。

## A16 张力

```
张力 = max(1 - c(生产地位), 1 - c(分配))
```

张力在每轮抽取前和修正前各算一次。它压低 A6 的有效修正，并在 A27 里给更贴近当前所有制的生产地位边和分配边加偏向。

1. 当前生产力不低于节点的最低生产力。

1. 节点未点亮、未废止。

# M4 历史条件

## A27 条件编译

在本轮点亮、废止和三轴迁移都完成之后执行。结果供下一轮抽取和修正使用。

1. 抽取倍率从 1 开始，轴偏向从 1 开始，修正偏置从 0 开始，门闩为空。

3. 用主导所有制给生产地位边和分配边加张力偏向：

```
差距 = 表(主导所有制, 边的终点) - 表(主导所有制, 该轴主导节点)
差距 > 0 时，该边偏向 +0.20
差距 < 0 时，该边偏向 -0.10
```

4. 夹取。倍率到 [0.5, 2]，轴偏向到 [0.5, 1.5]，修正偏置到 [-0.1, 0.1]。

玩家可见的条件标签，是相对缺省值有变化的倍率、偏向、偏置和门闩。

## A28 权重合成

A3 使用的倍率、A27 写出的轴偏向，都必须是夹取之后的数。调用方不再乘第二层未夹取的倍率。边的开放不读取倍率；倍率只影响以后事件里轴载荷出现时的说明权重，以及事件抽取本身。

## A29 门闩与修正读取

门闩集合原样交给 A8。修正偏置原样进入 A6。生产力模块据此改变候选和普通正增量，不回查是哪个节点写入的。

# 数值例子

开局选择 O0、L0、D0、互惠交换。初始上层建筑只有 P0，社会形态是原始社会，起点坐标 0，历史标记为空，条件快照是缺省值，张力是 0。

## 第一轮

P = 0 时，铜矿利用的下限是 4，定居与农业的下限是 12，蒸汽机的下限是 70，这些权重都是 0。青铜冶炼还缺少 `copper_use`。

基础修正：

```
石器 = exp(-((0 - 4) / 8) ^ 2) = exp(-0.25) = 0.779
采集 = exp(-((0 - 6) / 8) ^ 2) = exp(-0.5625) = 0.570
用火 = exp(-((0 - 2) / 10) ^ 2) = exp(-0.04) = 0.961
```

普通事件的最高修正是 0.779，高于 0.2，用火没有顶峰加成。权重为石器 0.779、采集 0.570、用火 `0.6 × 0.961 = 0.577`，总和 1.926。取 roll = 0.80，`0.80 × 1.926 = 1.541`，落在用火的区间。

用火的核心拼到起点上，坐标仍是 0。玩家选择「保存火种」。它是关键正确结果，设计增量 +6 不乘修正。生产力变为 6，写入 `fire_kept`。时代名为空，所以不提示新时代。

## 顶峰上的软锁

假设后来生产力到了 18，而且铜矿利用的「冷锻利用」已经走过，`copper_use` 存在。张力按 0、修正偏置按 0 计算。

```
石器 = exp(-((18 - 4) / 8) ^ 2) = exp(-3.0625) = 0.047
采集 = exp(-((18 - 6) / 8) ^ 2) = exp(-2.25) = 0.105
铜矿 = exp(-((18 - 10) / 6) ^ 2) = exp(-1.778) = 0.169
定居 = exp(-((18 - 18) / 6) ^ 2) = 1
```

石器的「熟练打制」设计增量是 +2，实际增量是 `2 × 0.047 = 0.094`。铜矿若再次出现，+1 的增益会乘到 0.169。普通事件的最高修正是 0.169，低于 0.2，定居与农业得到 3 倍顶峰加成。它的正确结果「定居发展农业」使用完整的 +12，生产力变为 30，提示进入农业时代，并写入 `age_agri`。

蒸汽机在这个坐标上仍然抽不到，因为 18 不在 70 到 140 的区间里。青铜冶炼因为已有 `copper_use`，并且 18 落在 16 到 40 里，可以进入候选。
