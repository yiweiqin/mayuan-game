生产力地图

地图有唯一起点

地图生成机制如下：

图是以起点为节点的有向图
每条新边，按照以下策略生成后继节点

每个时代有自己的核心结构库
每个核心结构都有一个源节点

普通结构 线性 一个起点一个终点（可以重叠使长度为1或多个串联） 具有一般效果 生产力+/-
关键结构 主题事件 具有一个源节点的图结构 具有多个终点 生成关键结构需要前置 即行走过特定的关键结构

生成后继节点时，在该位置从结构库中选取一个 在该位置生成核心结构的源节点

如何判定时代
生产力达到一定值

如何锁前置
软性锁 事件可能具有类似这种效果：
（长度为1的）线性事件增益-x%~100%
从而锁住生产力
这样只有关键结构可以推进生产力 关键结构还可以设置线性事件增益提升而恢复生产力锁
